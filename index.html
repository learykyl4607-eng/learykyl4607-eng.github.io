Core Mechanic

How Class Upgrades Work

Legionbound uses a synergy-based upgrade system. When a teacher class is on the field with its student class, it provides upgrade experience, eventually allowing the student to promote to the upgraded form.

The Rule

Each class teaches the next class in its loop simply by being present on the battlefield. Proximity is not required — having both classes on the field is sufficient.

Third Unlock Method

Skill Tree — Optimal Unlock Order

Fifteen classes must be unlocked through the skill tree. Prioritize classes that anchor long teaching sequences.

Easy Tier — 6 classes Mercenary · Guardian · Swashbuckler · Brawler · Druid · Shieldmage
1
Druid
Druid → Wizard (starter) → Battlemage → Shieldmage
Your starter Wizard is already on the field. Unlocking Druid extends the chain backwards, giving you multiple connected upgrades from one skill point.
2
Guardian
Shieldmage → Guardian → Smith → Knight (→ Priest, earned via achievement)
Unlocking Guardian opens Smith and Knight downstream. Priest comes free from achievements.
3
Swashbuckler
Swashbuckler → Gunslinger → Duelist (achievement) → Rogue (starter)
Swashbuckler starts the longest chain in the Agile loop. Duelist and Rogue are covered otherwise.
4
Brawler
Mercenary → Brawler → Barbarian → Warrior (starter)
Brawler anchors a strong segment that wraps back to your starter Warrior.
5
Mercenary
Tax Collector (achievement) → Mercenary → Brawler
Tax Collector comes free, so one skill point completes this Brutal segment.
6
Shieldmage
Battlemage → Shieldmage → Guardian
Closes the chain started earlier with Druid and Wizard.
Medium Tier — 9 classes Gunslinger · Paladin · Samurai · Knight · Bard · Sorcerer · Barbarian · Battlemage · Smith
1
Battlemage
Wizard (starter) → Battlemage → Shieldmage
Connects the Druid → Wizard chain through to Guardian.
2
Smith
Guardian → Smith → Knight → Priest (achievement)
One point completes a strong Heavy chain.
3
Sorcerer
Witch (achievement) → Sorcerer → Tax Collector (achievement)
Fills the only gap between two achievement classes.
4
Paladin
Priest (achievement) → Paladin → Cleric (starter)
Completes the segment with one skill point.
5
Barbarian
Brawler → Barbarian → Warrior (starter)
Closes the Heavy loop wrap.
6
Gunslinger
Swashbuckler → Gunslinger → Duelist (achievement)
Completes the Agile segment with one point.
7
Knight
Smith → Knight → Priest (achievement)
Fills the final gap in the Smith-Knight-Priest chain.
8
Bard
Monk (achievement) → Bard → Swashbuckler
Single link needed for this Agile segment.
9
Samurai
Ranger (starter) → Samurai → Artificer (achievement)
Completes the Agile loop wrap.

Class Synergy Loops

Each class grants upgrade experience to the next class in the loop when both are on the field. Follow the arrows clockwise.

⚔️ Agile Martial Loop 11 classes
Rogue → Duelist → Gunslinger → Swashbuckler → Bard → Monk → Barkeep → Herbalist → Ranger → Samurai → Artificer → back to Rogue
🛡️ Heavy & Caster Loop 14 classes
Wizard → Druid → Lumberjack → Warrior → Sorcerer → Witch → Cleric → Paladin → Priest → Knight → Smith → Guardian → Shieldmage → Battlemage → back to Wizard
💢 Brutal Economy Loop 4 classes
Barbarian → Brawler → Mercenary → Tax Collector → back to Barbarian
